# Atividade 01 — Projetos GitHub com Consumo de APIs

Pesquisa de 10 projetos no GitHub que consomem APIs. Cada projeto foi clonado nesta pasta e analisado (arquivos `package.json`, `pubspec.yaml`, `requirements.txt` e código-fonte) para identificar o framework utilizado e as APIs consumidas.

| PROJETO | LINK DO REPOSITÓRIO | FRAMEWORK | QUAIS APIs FORAM UTILIZADAS | LINK DE DEPLOY |
|---|---|---|---|---|
| Projeto 1 — ClimaBR (previsão do tempo) | https://github.com/ufla-gcc132/climabr | Ionic + Angular 15 (Capacitor) | OpenWeatherMap API (One Call) | Não disponível |
| Projeto 2 — Conversor de Moedas | https://github.com/team-ovly/conversor-moeda-html5 | HTML5 + jQuery + Bootstrap 4 (SAP Web IDE) | Exchange Rates API (exchangeratesapi.io) | Não disponível |
| Projeto 3 — Finder (buscador de promoções de jogos) | https://github.com/Rafa84/buscador_jogos | Python + PySimpleGUI (app desktop) | IsThereAnyDeal API | Não disponível (app desktop) |
| Projeto 4 — App de Filmes | https://github.com/Daniflav94/App-filmes | Angular 15 | TMDb API (The Movie Database) | https://api-filmes-1c278.web.app/login |
| Projeto 5 — Senai IBGE (dados do censo) | https://github.com/NannAlmeida/Senai-IBGE | React Native (Expo) + Axios | API de Serviço de Dados do IBGE (Censos) | Não disponível |
| Projeto 6 — Rick and Morty | https://github.com/paulo-magls/rick-and-morty-application | Angular 14 + Bootstrap 5 | The Rick and Morty API | https://rick-and-morty-web-page.netlify.app/ |
| Projeto 7 — Hotel Resilia Palace | https://github.com/CaioLima96/projetoModulo05 | React 17 + Axios | API REST própria (apihotelresiliapalace no Heroku) | https://hotelresiliapalace.vercel.app/ |
| Projeto 8 — Albion Prices (preços de itens do jogo) | https://github.com/jvoliveira/Albion-Prices | HTML + jQuery + Bootstrap 4 | Albion Online Data Project API | https://jvoliveira.github.io/Albion-Prices/ |
| Projeto 9 — GitHub Explorer | https://github.com/benrondeau/Github-Explorer | Angular 4 | GitHub REST API (`/users`) | https://benrondeau.github.io/Github-Explorer/dist/ |
| Projeto 10 — Pokédex | https://github.com/alanlgoncalves/pokedex | Flutter (Dart) + MobX + Dio | API própria de dados de Pokémon (pokedex.alansantos.dev/api) | https://pokedex.alansantos.dev |
